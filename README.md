# SafeSignal

SafeSignal is a React Native personal-safety app that lets users quickly share their location and status with trusted contacts.

## Overview
Users can create emergency contacts, trigger an alert with a long-press or shortcut, and share a temporary location link with a clear status message.

## Problem
In stressful situations, users need a fast, simple way to notify trusted people without navigating complex apps.

## Solution
SafeSignal prioritizes one-tap alerts, clear status sharing, and privacy-conscious location controls.

## Features
- Trusted-contact management
- One-tap emergency alert
- Temporary location sharing
- Check-in reminders
- Custom alert messages
- Offline message queueing

## Tech Stack
- React Native + Expo
- TypeScript
- expo-location
- Firebase / Supabase
- Push notifications
- Expo SecureStore
